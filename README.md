# SpendWise – Expense Tracker

SpendWise is a web-based personal expense tracking application developed as part of a Mobile Application Development assignment.

The project is designed using a hybrid application development approach. The web application is developed using HTML, CSS, and JavaScript and is converted into an Android application using Capacitor.

## Project Objective

The main objective of SpendWise is to help users manage their personal finances by recording income and expenses, monitoring spending habits, setting monthly budgets, and viewing financial summaries.

The same web application is packaged as a mobile application using Capacitor and Android Studio.

## Features

### 1. Dashboard
- View total balance
- View total income
- View total expenses
- View savings rate
- Quick overview of financial activity

### 2. Transaction Management
Users can:
- Add income
- Add expenses
- Edit transactions
- Delete transactions
- Select expense categories
- Add transaction descriptions
- Specify transaction dates

### 3. Search and Filtering
Transactions can be:
- Searched by description
- Filtered by type
- Filtered by category
- Sorted according to different criteria

### 4. Expense Categories

The application supports categories such as:

- Food
- Transport
- Shopping
- Bills
- Education
- Entertainment
- Health
- Other

### 5. Budget Management
Users can:
- Set monthly budgets
- Track spending against budgets
- Monitor remaining budget
- Identify categories with high spending

### 6. Financial Analytics
The application provides:
- Expense summaries
- Category-wise spending
- Income and expense comparison
- Monthly financial information
- Spending analysis

### 7. Dark Mode
Users can switch between:
- Light mode
- Dark mode

### 8. Local Data Storage
Transaction and budget information is stored using browser LocalStorage.

This allows the application to retain data even after the page is refreshed.

### 9. Responsive Design
The application is designed to work on:

- Desktop
- Tablet
- Mobile devices

The interface is optimized for mobile use before being packaged as an Android application.
